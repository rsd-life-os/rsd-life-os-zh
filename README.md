# RSD人生优化系统（RSD Life OS）

**明明知道该做什么，就是做不到；同一个冲突，在最亲的关系里反复重演；钱来了又走，怎么也留不住；书读了一堆，道理都懂，生活照旧。**

这个技能，就是为这些时刻造的。

一套完整的人生操作系统，编译自 **谷阳（RSD Kin）** 所著《RSD人生优化系统》（*RSD Life OS*）：六大命名工具、三大宇宙法则、三大身份、四大旅程，以及 2=1+1 的道理透视镜——每一件都有明确用途、操作程序和失效模式。

不是励志，不是概念，是**工具箱**——卡住的时候，按程序走。

## 安装

Agent Skill 是根目录带 `SKILL.md` 的目录。克隆到你所用智能体的 skills 目录：

```bash
git clone https://github.com/rsd-life-os/rsd-life-os-zh.git
# 再将智能体的技能加载器指向本目录
```

兼容任何支持 Agent Skills 开放标准（SKILL.md + 按需懒加载资源文件）的智能体。

## 30 秒框架

- **2=1+1** —— 万物 = **道**（生命能量、驱动力）+ **理**（运行法则、形式）。先读形式，后命名能量。
- **六大工具** —— 分析法（真相洞察器）· 唤醒法（主权复位器）· 重组法（命运优化器）· 充电法（身心充电器）· 观测法（身体管理器）· 导航仪（行为校准器）。
- **三大宇宙法则** —— 生存法则（存在与延续）· 行为法则（无为、利他、平等）· 因果法则（行为考评与能量结算）。
- **RSD 行为码** —— R（担当）→ S（洞察）→ D（顺势）。次序是承重墙。

## 范围与硬边界

本技能是**书的伴读物，不是替代品**。它索引并运用作者框架，不复述原文。

- **不构成医疗、心理、财务建议。** 有病看医生；有危机，立即寻求人的帮助。
- **不预测未来。** 本书明确禁止。
- **不招募、不销售、不推广。** 无产品、无下线、无会员漏斗。
- **不保证效果。** 结果取决于实践的准确、频繁、深入与持续程度。
